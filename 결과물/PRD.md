# PRD: ETC·제한차량 단속설비 공사 현장관리 웹사이트

> 작성일: 2026. 11. 11. / 작성: 서울경기본부 교통부 ITS팀 ( )

## 1. 배경

- ETC·제한차량 단속설비 교체·신설 사업이 여러 개이고 시공사도 많아, 현재는 단체 카톡방(시공사·감리·도공감독)으로 작업 시작·종료를 보고받고 있음
- 그날 작업은 확인하기 쉬우나, **지난 작업 이력은 대화를 거슬러 올라가야 찾을 수 있고 공정률은 알 수 없음**
- 카톡방을 대신해 **공정률, 오늘 작업, 안전 준수 여부를 한 화면에서** 확인하는 웹사이트를 만듦

## 2. 사용자

| 구분 | 사용자 | 기기 | 하는 일 |
|---|---|---|---|
| 입력 | 시공사 현장 담당자 | 휴대폰 | 작업 시작·종료 보고, 사진·TBM일지 첨부, 준수항목 체크 |
| 조회 | 감리, 도공감독 | PC | 현황 조회, 보고 확인 체크 |

## 3. 기능 (필수 3개 + 사업 관리)

1. **작업 보고 입력(모바일)**
   - 시작 보고: 사업, 작업차로·개소, 작업 내용, 시작 시간, 시공사, 담당자, 현장사진, TBM일지, 준수항목 5개 체크
   - 종료 보고: 종료 시간, 완료 사진, **완료 개소 체크**(공정률에 반영)
2. **현황 대시보드(PC)**
   - **오늘 작업 위치**: 맨 위에 영업소별로 묶어 크게 표시 (현장 확인용)
   - 사업별 공정률 = 완료 개소 ÷ 전체 개소 (자동 계산)
   - 오늘 작업 목록(진행 중/종료)
   - 준수 여부: 5개 항목이 모두 충족되면 초록(준수), 하나라도 빠지면 빨강(미준수)
3. **작업 이력 조회**
   - 사업·시공사·개소·기간으로 필터해 지난 작업 보고를 찾고, 사진과 TBM일지를 다시 확인
4. **사업 관리(PC, 2026. 11. 11. 추가)**
   - 사업 등록·수정: 사업명, 업체명, 계약기간, 담당자, 담당자 연락처, 영업소
   - 작업 개소를 한 줄에 하나씩 등록 (공정률 계산의 전체 개소 수). 개소마다 영업소가 다르면 `개소명 / 영업소`로 적음
   - 작업 보고가 있는 개소는 삭제할 수 없음

## 4. 현장 준수항목 (작업 시작 보고 시 체크)

| 번호 | 항목 | 판정 |
|---|---|---|
| 1 | TBM 실시 및 TBM일지 첨부 | 체크 + 파일 |
| 2 | 작업장 표지 설치(주의 → 완화 → 작업 구간) | 체크 + 사진 |
| 3 | 신호수 2명 이상 배치 | 차로 차단 작업일 때만 |
| 4 | 허용 시간 내 작업(주간 09:00~17:00, 야간 22:00~06:00) | 입력 시간으로 **자동 판정** |
| 5 | 경광등·화살표 차량, 반사 조끼 | 야간 작업일 때만 |

## 5. 화면 구성

| 화면 | 사용자 | 주요 내용 |
|---|---|---|
| ① 대시보드 | 감리·도공감독 | 오늘 작업 위치(영업소별), 사업별 공정률 막대, 오늘 작업 카드, 미준수 건수 |
| ② 작업 보고 입력 | 시공사 | 시작/종료 보고 폼(모바일 한 화면) |
| ③ 작업 이력 | 전체 | 필터 + 목록, 클릭하면 상세(사진·TBM일지·준수항목) |
| ④ 사업 관리 | 도공감독 | 사업 목록(공정률 포함), 등록·수정 폼 |

## 6. 이번 범위에서 제외

- 로그인·권한 관리(1차는 더미 데이터로 화면만 구현)
- 금액 기준 기성·공정률, 알림(카톡·문자) 발송, 공문 자동 작성
