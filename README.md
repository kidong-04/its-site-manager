# ETC·제한차량 단속설비 공사 현장관리

단체 카톡방으로 받던 작업 시작·종료 보고, 현장사진, TBM일지를 웹사이트로 옮겨서
**공정률, 오늘 작업 위치, 안전 준수 여부**를 한 화면에서 확인하는 시안입니다.

## 열어 보기

[결과물/site/index.html](결과물/site/index.html)을 내려받아 더블클릭하면 브라우저에서 열립니다. 더미 데이터가 파일 안에 들어 있습니다.

## 화면

| 화면 | 사용자 | 내용 |
|---|---|---|
| 대시보드 | 감리·도공감독 | 오늘 작업 위치(영업소별), 사업별 공정률, 미준수 현황 |
| 작업 보고 | 시공사(휴대폰) | 작업 시작·종료 보고, 사진·TBM일지, 현장 준수항목 체크 |
| 작업 이력 | 전체 | 사업·개소·시공사·기간 필터, 상세 보기, 감리·감독 확인 |
| 사업 관리 | 도공감독 | 사업명, 업체명, 계약기간, 담당자, 연락처, 영업소, 작업 개소 |

## 한계 (1차 범위 밖)

- 로그인·서버 저장 없음. 입력한 내용은 그 브라우저에만 저장됩니다.
- 업체명, 담당자, 연락처, 개소 위치(km)는 가상 데이터입니다.
